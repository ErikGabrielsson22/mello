# mello

dataplan: 
Artist: Artist namn, bild på artist
Bidrag: låtitel, låtskrivare
Deltävlingar: stad,datum

Projektet byggd med det alternativa spåret. Backend består av api.php som levererar städer och artister som JSON.

Frontend använder index.php som grund, css för designen, och app.js som gör en fetch() mot API:et. JavaScript-koden använder enkla for-loopar och if-satser för att visa rätt bidrag utan att sidan laddas om
